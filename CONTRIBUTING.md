# Contributing

Thanks for helping make everyday cloud checks clearer.

- Only use synthetic or sanitized billing, IAM, and Kubernetes examples. Never submit real account exports or policies.
- Keep the commands local and read-only. They must not request credentials, call cloud APIs, or apply changes.
- Describe a finding as a review prompt unless it can be proven from the input alone.
- Include the rule ID and a small example when reporting an issue.

This is an early learning project; review and releases may take time.
